## Resumo

Este trabalho apresenta o desenvolvimento de um protótipo de apoio à decisão para análise de vendas e priorização de oportunidades em equipes B2B. O escopo final reúne importação e validação de dados, indicadores comerciais, fila de revisão, experimento de aprendizado de máquina e consultas em linguagem natural executadas por funções controladas do sistema. O método combina pesquisa aplicada, desenvolvimento incremental de software e avaliação experimental retrospectiva. A implementação avaliada importa de forma reproduzível uma base pública fictícia com 8.800 oportunidades, disponibiliza uma interface web integrada a uma API e utiliza persistência local ou PostgreSQL com políticas de segurança em nível de linha. O código foi dividido em módulos de leitura e validação dos arquivos, importação transacional, consultas de indicadores, autenticação, rotas da API e interface. Foram executados 23 testes automatizados. O experimento preditivo comparou uma referência simples, regressão logística e árvore de decisão após divisão temporal dos dados. Os resultados não demonstraram ganho suficiente para tratar as probabilidades dos modelos como confiáveis. Por esse motivo, a fila utiliza critérios transparentes, enquanto o aprendizado de máquina permanece como parte da avaliação acadêmica. A camada de linguagem natural integra o escopo do protótipo final, mas seus resultados somente poderão ser apresentados depois da implementação e de testes específicos. Também permanecem necessárias a avaliação com usuários e a validação com dados reais autorizados.

Palavras-chave: análise de vendas; priorização de oportunidades; aprendizado de máquina; sistemas de apoio à decisão; inteligência artificial.

## Abstract

This study presents the development of a decision-support prototype for sales analysis and opportunity prioritization in B2B teams. Its final scope combines data import and validation, sales indicators, a review queue, a machine-learning experiment, and natural-language queries executed through controlled system functions. The method combines applied research, incremental software development, and retrospective experimental evaluation. The evaluated implementation reproducibly imports a fictional public dataset containing 8,800 opportunities, provides a web interface integrated with an API, and supports either local persistence or PostgreSQL with row-level security policies. The code is organized into modules for file reading and validation, transactional import, indicator queries, authentication, API routes, and the user interface. Twenty-three automated tests were executed. The predictive experiment compared a simple baseline, logistic regression, and a decision tree after a temporal data split. The results did not show sufficient improvement to treat model probabilities as reliable. The review queue therefore uses transparent criteria, while machine learning remains part of the academic evaluation. The natural-language layer belongs to the final prototype scope, but its results can only be reported after implementation and specific testing. User evaluation and validation with authorized real-world data are also still required.

Keywords: sales analysis; opportunity prioritization; machine learning; decision-support systems; artificial intelligence.
